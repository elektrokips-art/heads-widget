# Heads Widget

Бесплатный Android-виджет для рабочего стола, показывающий заряд TWS-наушников (левый/правый
эрбад + кейс) без привязки к бренду — и без необходимости открывать флаки-приложение
производителя после каждого разрыва соединения.

## Почему

У официальных приложений (в первую очередь замечено на Sony | Headphones Connect) нет
виджета для батареи, а сами приложения часто отваливаются от наушников и требуют ручного
переподключения. Задача этого проекта — убрать это трение: заряд виден сразу с рабочего
стола, без действий пользователя.

## Что делает

- Виджет на рабочий стол: L/R/кейс (или общий %, если бренд не даёт раздельных данных),
  индикатор подключения, время последнего обновления
- Автообновление при подключении/отключении наушников (без открытия приложения)
- ANC-переключатель (Выкл / Шумоподавление / Прозрачность) — в приложении всегда, в самом
  виджете появляется, если растянуть его на 2+ ячейки по высоте
- Настройка внешнего вида виджета: цвет, прозрачность, скругление углов, интервал обновления
- Тёмная/светлая тема, 4 языка (ru/uz/en/tr)

## Поддержка брендов

Протоколы у большинства производителей проприетарные и нигде официально не задокументированы.
Реализация в этом проекте основана на изучении открытых проектов
[Gadgetbridge](https://codeberg.org/Freeyourgadget/Gadgetbridge) (AGPL-3.0),
[OpenPods](https://github.com/adolfintel/OpenPods) (GPL-3.0) и
[CoreSound](https://github.com/CriticalRange/CoreSound) (GPL-3.0), а таблица UUID моделей
Soundcore — из декомпиляции официального приложения Soundcore (interoperability reverse
engineering, тот же принцип). С нуля переписано на Kotlin — не копипаста чужого кода, а
собственная реализация того же протокола связи.

| Бренд | Батарея | ANC | Статус |
|---|---|---|---|
| Sony (LinkBuds S) | L/R/кейс раздельно | Off/NC/Ambient | ✅ подтверждено на реальном железе |
| Realme / Oppo / OnePlus / vivo (BBK) | L/R/кейс раздельно | — (протокол не даёт) | ✅ батарея подтверждена (Realme); OnePlus/vivo — то же имя протокола, не проверено отдельно |
| Anker Soundcore (101 модель из каталога) | L/R/кейс раздельно | Off/NC/Ambient | ⚠️ переписано на SDP+UUID по официальному приложению (per-модельный UUID вместо перебора канала), ещё не проверено после переписывания |
| Apple AirPods / Beats | L/R/кейс раздельно | — (другой протокол, не реализовано) | ⚠️ реализовано, не проверено на железе |
| Любой другой Bluetooth-девайс | Общий % (если ОС его знает) | — | резервный вариант, работает почти всегда |

Если бренд не распознан или его протокол не ответил — виджет тихо показывает общий процент
через системный API вместо того, чтобы ничего не показывать.

## Сознательные ограничения

Проект специально не лезет в настройки экватайзера, жестов и прочего — только базовая инфа
и базовое управление. Это не замена приложению производителя, а лёгкая бесплатная альтернатива
для одной конкретной задачи: видеть заряд без танцев с бубном.

## Технически

- Flutter-приложение — только настройка и диагностика
- Вся Bluetooth-логика на Kotlin (`android/app/src/main/kotlin/com/gesys/linkbuds_widget/`),
  чтобы виджет обновлялся и при закрытом Flutter-движке
- `BatterySource`/`AncControlSource` — подключаемые источники по бренду (`BatterySource.kt`,
  `AncControl.kt`), резервный fallback — скрытый `BluetoothDevice.getBatteryLevel()`
